# MeatColor support

## Usage questions

First review the README, function documentation, and introductory vignette.
If the question remains, open a
[GitHub issue](https://github.com/JustSplash8501/MeatColor/issues) with a small
reproducible example and the output of `sessionInfo()`.

## Bug reports and feature requests

Use the GitHub issue tracker for reproducible bugs and focused feature
requests. Reports about unexpected colors should state the colorimeter's
color space, illuminant, observer angle, and the complete L*, a*, and b*
inputs. Do not post confidential data.

## Security and private matters

Do not disclose a suspected security vulnerability in a public issue. Contact
the package maintainer privately using the email in the `DESCRIPTION` file.
The same private contact may be used for conduct reports that should not be
discussed publicly.

Support is provided on a best-effort basis. The maintainers do not guarantee a
response time or individualized analysis of research data.
